# StudyMate — PWA

## Выложить на GitHub Pages
1. Создайте репозиторий на github.com (публичный: для приватного Pages нужен платный план).
2. Загрузите **всё содержимое** этой папки, включая скрытую `.github`.
3. Settings → Pages → Source: **GitHub Actions**.
4. Вкладка Actions → дождитесь зелёной галочки «Deploy PWA». Адрес: `https://<логин>.github.io/<репозиторий>/`.

## Установить
- Android (Chrome): меню ⋮ → «Установить приложение».
- iPhone (Safari): «Поделиться» → «На экран Домой».

## Обновлять
Правите `index.html`, делаете push — сайт обновится сам. Приложение подхватит новую версию при следующем запуске с интернетом.

## Что учесть
- Данные из APK и из браузера не переносятся: у PWA своё хранилище.
- Уведомления о дедлайнах приходят, пока приложение открыто. На iPhone нужен iOS 16.4+ и установка на экран Домой.
- Без интернета приложение работает из кэша.

## Что изменено по сравнению с APK-версией
- Пользовательский ввод экранируется перед выводом (`escapeHtml`) — закрыта HTML-инъекция.
- Добавлена Content-Security-Policy: внешние скрипты, картинки и сетевые запросы запрещены.
- Уведомления идут через service worker (в Android Chrome `new Notification()` не работает).
